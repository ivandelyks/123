# Тестовый класс для Me2MeTransferService

## Описание

Создан тестовый класс `Me2MeTransferTestCase1` для проверки функциональности перевода между своими счетами (Me2Me). Класс основан на структуре `CashFlowManagerTestCase1` и адаптирован для работы с операцией типа `TRANSFER_ME2ME`.

## Структура теста

### Основной тестовый класс
- **Файл**: `Me2MeTransferTestCase1.java`
- **Наследование**: `CashFlowManagerTestCase`
- **Аннотации**: `@System("CI10097750")`, `@DisplayName`, `@Test`

### Тестовые данные
- **Офис**: `VSP_38_5278_01032`
- **Карта списания**: `MIR_SBERCARD` (номер: 22022032FD011111)
- **Карта зачисления**: `VISA_CLASSIC` (номер: 22022032FD022222)
- **Сумма перевода**: 10000.00

## Сценарий тестирования

### Шаг 1: Получение предложений
- **Действие**: Запрос предложений по распределению средств
- **Ожидаемый результат**: Получение предложения на перевод между своими счетами
- **Mock файлы**: 
  - `get_operation_predictions.json` - предсказания операций
  - `giga_chat_1.json` - ответ GigaChat с предложением

### Шаг 2: Согласование предложения
- **Действие**: Пользователь соглашается с предложением
- **Ожидаемый результат**: Переход к выполнению операции
- **Mock файлы**:
  - `giga_chat_2.json` - подтверждение от GigaChat
  - Данные профиля пользователя

### Шаг 3: Выполнение операции
- **Действие**: Получение результата от Workflow адаптера
- **Ожидаемый результат**: Успешное выполнение перевода
- **Сообщение**: "Перевод между своими счетами успешно выполнен"

## Вспомогательные классы

### GetOperationPredictionMockRs
Mock класс для ответа с предсказаниями операций от PFM сервиса.

### MakeOfferResponse
Класс для ответа от GigaChat с предложениями операций.

### OperationOffer
Класс для описания предложения операции с атрибутами.

### PersonProfileData
Класс для данных профиля пользователя с информацией о картах.

## Отличия от CashFlowManagerTestCase1

1. **Тип операции**: `TRANSFER_ME2ME` вместо `PAYMENT_MOBILE`
2. **Атрибуты**: 
   - `cardNumberFrom` - карта списания
   - `cardNumberTo` - карта зачисления  
   - `amount` - сумма перевода
3. **Описание**: "Перевод между своими счетами в Сбере"
4. **Сообщения**: Адаптированы под сценарий перевода между счетами
5. **Тестовые данные**: Используются две карты (списания и зачисления)

## Запуск теста

Тест можно запустить как обычный JUnit тест. Он будет использовать мок-конфигурации для имитации ответов от внешних сервисов (PFM, GigaChat, PersonProfile).

## Требования

- JUnit 5
- Spring Test
- Jackson для работы с JSON
- Доступ к базовому классу `CashFlowManagerTestCase`
- Настроенные мок-конфигурации в `AppMockConfigs`
